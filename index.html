GitHub 多端同步

在 GitHub → Settings → Developer settings → Personal access tokens 创建，Fine-grained 类型，只勾选你那个仓库的 Contents: Read and write 权限。Token 只存在本机浏览器里。
一个私有仓库，所有设备共享这一份数据文件。
仓库内的路径，一般不用改。
  1. 在 GitHub 创建一个私有仓库（Private），如 schedule
  2. 创建 Fine-grained PAT：Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，Repository access 选 Only select repositories 并勾选刚建的仓库，Permissions → Repository permissions → Contents 设为 Read and write
  3. 把 Token 和仓库名填到上面，点「测试连接」
  4. 之后每台设备打开这个网页，改动会自动双向合并同步
同步是按日期合并的：不同设备上写的备忘录、调的课都会保留，同一处的冲突取修改时间较新的一方。课表本身取较新版本。

数据备份

导出的 JSON 是完整备份（不含 Token），可在任意设备导入。同步之外多留一份本地备份更安心。

部署与使用

  1. 本文件是单文件应用（配套一个 sw.js 离线缓存），无需服务器
  2. 想手机/平板/电脑都能打开同一地址：把 index.html 和 sw.js 传到任意静态托管（GitHub Pages、Vercel、Netlify、腾讯云静态托管都行），用浏览器打开那个网址即可
  3. 手机上可以「添加到主屏幕」，用起来像 App
  4. 本地双击 index.html 也能用全部功能，只是 GitHub 同步需要在 http(s) 环境下
